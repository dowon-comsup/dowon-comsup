임금채권부담금 경감(환급) 계산기

퇴직연금 가입 사업장의 임금채권부담금 경감 적격성 검토 및 환급 추정액을 산출합니다.

임금채권보장법 §9·§10 / 시행령 §14·§15 / 시행규칙 §9
1
사업장 기본 정보
본·지사 합산 신청 시 법인등록번호 기준으로 모든 관리번호 포함
DC 복수 운용사 시 운용사별 가입확인서 각 1장
경감 신청 불가 퇴직연금(DC/DB형), 중간정산, 출국만기보험, 보증보험 중 하나 이상 가입해야 경감 신청이 가능합니다.
2
연도별 보수총액·납부 내역
확인 방법: 근복 토탈서비스 → 사업장 → 보험료 납부내역 조회 기준요율(0.6‰)은 고용노동부 고시로 매년 변경될 수 있습니다. 납부 연도별 고시를 확인 후 입력하세요.
보험연도 보수총액 (원) 기준요율 (‰) 임채부담금 납부액 (원) 소멸시효
3
퇴직연금 가입현황 (산출기준일: 각 검토연도 전년도 말일)
DC형 가입확인서의 가입기간 합계와 근속년수 합계를 입력합니다.
복수 운용사인 경우 중복가입자를 제외한 실인원 기준으로 합산합니다.
DB형은 적립비율을 % 단위로 입력합니다 (예: 79.20 입력 → 내부 0.792로 환산).
주간사 통합 발급 권장. 미발급 시 운용사별 합산 후 중복가입자 제외.

신청 절차

1
퇴직연금 운용사 → 가입확인서 수령
산출기준일: 검토 연도 전년도 말일 기준 · 연도별 1장 · DB형은 주간사 통합 발급 권장
2
근복 토탈서비스 → 임채부담금 경감 신청
민원접수/신고 → 임채부담금 경감 신청 · DB형: 적립비율 입력 시 % 값 ÷100 환산 필수 (예: 79.20 → 0.792)
3
과납금 환급 계좌 신청 (별도 절차)
민원접수/신고 → 보험료신고 → 과납금 환급 계좌 신청 · 경감 신청과 별도로 반드시 진행
4
처리 확인 (약 2개월)
신청 후 1주 → 요율 변경 확인 · 1개월 → 과납 보험료 발생 확인 · 2개월 → 환급 처리 확인
주의사항 · 본 계산 결과는 추정값이며 도원 어드민 자동 산출값과 대조 후 최종 확인하세요.
· DB형 복수 운용사인 경우 중복 가입자 제외 실인원 계산이 필요합니다.
· 퇴직정산분(해당 연도 퇴사자 기준)이 별도로 발생할 수 있습니다 — 퇴사자 있으면 공단 유선 문의.
· 공단의 과납 보험료 처리 누락 가능 → 신청 후 2개월 시점 반드시 재확인.
